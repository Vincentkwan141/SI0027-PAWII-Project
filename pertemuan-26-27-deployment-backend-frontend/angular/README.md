# Mini Project - Angular Standalone + Konfigurasi Deployment

Lihat README utama pada folder [`pertemuan-26-27-deployment-backend-frontend`](../README.md) untuk penjelasan lengkap deployment, cara menjalankan backend, dan kaitannya dengan Tugas Project Mandiri.

Kode identik dengan Pertemuan 23-24-25 (masih berisi `// TODO` HttpClient/JWT pada `services/`, `interceptors/`, dsb.), ditambah `vercel.json` & `netlify.toml` (output direktori: `dist/mini-project/browser`). Jalankan cepat secara lokal:

```bash
npm install
npm start
```
