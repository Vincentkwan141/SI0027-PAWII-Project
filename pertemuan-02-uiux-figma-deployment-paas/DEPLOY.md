# Panduan Deployment - Pertemuan 2

Ikuti langkah berikut untuk mendeploy folder `static-site/` setelah TODO pada `style.css` selesai dikerjakan.

## Opsi A: Deploy ke Vercel

- [ ] 1. Buat akun di [vercel.com](https://vercel.com) menggunakan akun GitHub.
- [ ] 2. Push folder `static-site/` ke repositori GitHub Anda sendiri.
- [ ] 3. Pada dashboard Vercel, pilih **Add New Project** lalu hubungkan repositori tersebut.
- [ ] 4. Biarkan pengaturan default (tidak perlu build command untuk HTML statis), lalu klik **Deploy**.
- [ ] 5. Catat URL yang diberikan Vercel setelah deployment selesai.

## Opsi B: Deploy ke Netlify

- [ ] 1. Buat akun di [netlify.com](https://netlify.com) menggunakan akun GitHub.
- [ ] 2. Pilih **Add new site → Import an existing project**, lalu hubungkan repositori GitHub Anda.
- [ ] 3. Set folder `static-site/` sebagai *publish directory*.
- [ ] 4. Klik **Deploy site** dan catat URL yang diberikan.

## Yang Perlu Dilampirkan pada Laporan Praktikum

- Tautan (URL) hasil deployment yang dapat diakses publik.
