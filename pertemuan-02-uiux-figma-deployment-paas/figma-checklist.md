# Checklist Praktik Figma - Pertemuan 2

Figma adalah alat desain berbasis web sehingga tidak dapat disertakan sebagai berkas dalam repositori ini. Gunakan checklist berikut sebagai panduan praktik di [figma.com](https://www.figma.com).

## Studi Kasus Latihan

Gunakan studi kasus yang sama dengan materi slide: **redesign navigasi aplikasi akademik kampus** (mahasiswa kesulitan menemukan jadwal kuliah & nilai).

## TODO Checklist

- [ ] **Wireframe** - buat 3 frame low-fidelity: Halaman Beranda, Halaman Jadwal Kuliah, Halaman Nilai. Fokus pada tata letak, bukan warna/tipografi.
- [ ] **Mockup** - lengkapi wireframe dengan warna, tipografi, dan ikon agar mendekati tampilan akhir.
- [ ] **Prototype** - hubungkan ketiga frame sehingga dapat disimulasikan: Beranda → Jadwal Kuliah, Beranda → Nilai.
- [ ] **Uji Coba** - minta 1-2 teman mencoba prototype, catat kesulitan yang mereka temui.
- [ ] **Ekspor** - ambil tangkapan layar (screenshot) setiap frame untuk dilampirkan pada laporan praktikum.

## Kaitan dengan Tugas Project Mandiri

Checklist ini adalah latihan pendamping di kelas, **bukan** jawaban dari Tugas Project Mandiri (wireframe/prototype untuk ide project akhir Anda sendiri). Tugas tersebut dikumpulkan secara terpisah melalui LMS.
